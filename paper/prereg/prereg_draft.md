## 1. Study information

**Вопрос.** Связан ли размер колонии вида с объёмом мозга его рабочих? Сравнение идёт при равном размере тела и с учётом родства видов.

**Гипотезы.** Все направления заданы для наклона β₂ при log10(размер колонии) в основной модели (раздел 6).

| Гипотеза | Суть | Предсказание |
|---|---|---|
| **H1. Распределённое познание / дешёвый рабочий** | В большой колонии часть решений принимает коллектив, поэтому отдельному рабочему нужен меньший мозг. Мозг — дорогая ткань, и в больших колониях на ней экономят. Ср. кутикулу у Matte 2025 | **β₂ < 0** |
| **H2. Социальный мозг** | Жизнь в большом и сложном обществе требует от особи больше обработки сигналов | **β₂ > 0** |
| **H0. Практического эффекта нет** | Связь меньше наименьшего значимого эффекта | \|β₂\| < 0.02 |

**Оговорка.** Знак β₂ не отличает «распределённое познание» от «экономии на дорогой ткани»: обе идеи предсказывают β₂ < 0. Мы проверяем направление и величину связи, а не механизм. Механизм разбирают вторичные анализы (раздел 9).

## 3. Variables

**Отклик — log10 объёма мозга, мм³, у каждого рабочего.**
- Маска nnU-Net: сеть «йод» или «без окраски».
- Мозг = надглоточный ганглий с оптическими долями + подглоточная зона, как в метках Toulkeridou 2023. `[TODO: сверить точное определение с README набора Dryad и записать]`.

**Предиктор — log10 размера колонии вида.**
- Среднее геометрическое средних размеров гнезда по записям S3.
- Если в S3 записей нет — `colony.size` из Bell-Roberts 2024. В v2 так получено 8 видов из 352.

**Размер (основная ковариата) — log10 объёма всего тела.**
- Берётся из S1, если экземпляр там есть, иначе из нашей маски тела.
- Сдвиг объёма тела, если он есть, меряется на экземплярах S1 и указывается в тексте.

**Почему тело, а не мягкие ткани.**
- Мягкие ткани у нас есть только для ~172 видов из S1.
- Смещение от тела мы измерили заранее (модель M7 узла кутикулы): при равных мягких тканях объём тела падает на 0.0069 log10 на каждую единицу log10 колонии (95 % ДИ 0.0038–0.0100).
- При наклоне «мозг — тело» около 0.7 это сдвигает β₂ примерно на **+0.005**, то есть к нулю и против H1.
- Поэтому для H1 тест консервативен. Для H2 о смещении пишем прямо. Мягкие ткани и голова — проверки R3.

**Ковариаты.**
- Окраска вида: йод / без окраски.
- Класс шага: 1.22, 2.44 или 6.11 мкм; 8.2 мкм присоединяется к 6.11.

## 4. Inclusion and exclusion rules

Правила применяются по порядку и до соединения с колониями. Счёт отсева по каждому шагу идёт в отчёт.

**Экземпляры.**
1. Каста `worker` по метаданным AntScan; внешние группы исключены.
2. Основной анализ — малые и мономорфные рабочие. Исключены `caste_detail` ∈ {major, media, intercaste}. Вид, у которого остались только крупные касты, выпадает из основного анализа и входит в R6.
3. Повреждения по `problems_det/other`:
   - экземпляр исключается при «head truncated», «anteriorly truncated», «truncated» без уточнения, «no_scan», «oversaturated», «soft tissues badly preserved»;
   - при «gaster truncated» и «posteriorly truncated» экземпляр выпадает только из оценки объёма тела.
4. Автофлаги, ставятся вслепую к колонии:
   - маска касается края рамки;
   - самый крупный связный кусок меньше 90 % маски;
   - разброс объёма между 5 свёртками, CV > 15 %;
   - доля мозга от тела вне 0.05–10 %. Это грубая граница правдоподобия, не отклонение от линии «мозг — тело».
5. Слепой просмотр: все флагованные и 100 случайных наложений. Маска «негодна» → экземпляр исключён.

**Виды.**

6. Есть видовой эпитет; морфовиды (`sp.`, коды) исключены. Имена с `cf.`, `aff.`, `nr.` относятся к виду — как у владельцев; без них — проверка R7.
7. Есть видовой размер колонии.
8. Вид поставлен в дерево функцией `pgls.match_species`. Порядок:
   - точное имя;
   - подвид;
   - перенос рода из закреплённого списка `GENUS_TRANSFERS`;
   - свободная ветка того же рода — флаг `genus_placed`.

   Иначе вид исключается.
9. Остался хотя бы один годный рабочий.

**Среднее по виду.**
- Среднее log10 объёмов годных рабочих одного способа подготовки.
- Если у вида есть неокрашенные рабочие — берутся только они, иначе йодные.
- Класс шага вида — самый частый среди взятых экземпляров.

**Ожидаемое n:** 349 видов до контроля качества, 310–340 после.

## 5. Gates before the main test

Обе проверки проходят без таблицы колоний.

**Ворота № 2 — точность измерения.**

| Мера | Порог |
|---|---|
| Ошибка объёма мозга на 20 отложенных неокрашенных, размеченных человеком, медиана модуля | ≤ 10 % |
| То же для сети «йод» на 30 тестовых видах Toulkeridou | ≤ 7 % |
| Dice на отложенных | ≥ 0.90 |
| Повторяемость: ICC(1) log10 объёма мозга у видов с ≥ 2 годными рабочими | ≥ 0.80 |
| Сдвиг от окраски на 23 видах «йод + без окраски» | оценён с 95 % ДИ |

- Если сдвиг от окраски по модулю больше 0.10 log10, основной анализ идёт только на неокрашенных, а йодные виды переходят в проверку.
- Порог не взят → ещё один круг доразметки. Не взят и после него → препринт на йодных и годных неокрашенных экземплярах, с оговоркой (`fast-path.md`, раздел 7).

**Ворота № 3 — правило Галлера, положительный контроль.**
- Модель: log10 мозга ~ log10 тела + окраска + класс шага. PGLS-λ на дереве MCC, без колонии.
- **Проходит, если выполнены все три условия:**
  - наклон по телу лежит в [0.4; 0.9];
  - 95 % ДИ наклона целиком внутри (0; 1);
  - R² обычной регрессии средних по видам > 0.5.
- Ориентир — наклон 0.5–0.8 по Seid 2011 и Perl 2026.
- Если не проходит, гипотезу не тестируем: чиним измерение и повторяем ворота № 2–3. Это отклонение пишем в отчёт.

## 6. Analysis plan: primary test

**Одна модель, один тест — наклон β₂.** Уровень вида:

```
log10(Brain_s) = β0 + β1·log10(Body_s) + β2·log10(Colony_s) + β3·[Iodine_s] + β4·[Vox1.22_s] + β5·[Vox6.11_s] + ε_s
ε ~ N(0, σ²·C_λ),   C_λ = λ·C + (1 − λ)·diag(C)
```

- **C** — общий путь от корня по дереву Economo 2018 MCC `15k_NCuniform_stem_mcc.tre`. Это дерево владельцев.
- **λ** — Pagel, по максимуму правдоподобия в [0; 1]; 95 % ДИ — по профилю правдоподобия.
- **Вывод:** оценка β₂, 95 % ДИ по t с n − 6 степенями свободы, двусторонний p. Тест один, поправки на множественность нет.
- **Программа:** `pgls.pgls_lambda`, Python 3.13. Сверка на итоговых данных — `phylolm` 2.6.5 и `nlme::gls(corPagel)` в R 4.6.2 (`src/analysis/phylolm_check.R`). Расхождение больше 1e-4 по β₂ — ошибка, анализ останавливается.

**Неопределённость дерева — обязательная часть отчёта.**
- Та же модель на 100 апостериорных деревьях NC-stem.
- Объединённый 95 % интервал — смесь t-распределений по деревьям (`pgls.summarize_over_trees`).
- Доля деревьев с p < 0.05.

**Модель с ошибкой измерения — заранее заданная проверка устойчивости.** brms, уровень экземпляра:

```
log10 Brain_ij | se(m_ij, sigma = TRUE) ~ log10 Body_ij + log10 Colony_j + Iodine_ij + VoxClass_ij
                                         + (1 | gr(species, cov = A)) + (1 | species)
```

- **m_ij** — известная SD измерения log10 мозга: ошибка на отложенных плюс разброс между свёртками.
- **A** — корреляционная матрица дерева MCC.
- **Априорные:** β ~ N(0, 0.5); свободный член ~ t₃(0, 2.5); SD ~ полу-t₃(0, 0.5).
- **Прогон:** 4 цепи × 2000 итераций. Требования: R-hat < 1.01, ESS > 400.
- Если brms поставить не удастся, тот же модельный ряд считается в MCMCglmm. Это отклонение.

## 7. Inference criteria and decision rules

**Наименьший значимый эффект, SESOI: |β₂| = 0.02.**
- В пересчёте: 4.7 % объёма мозга на десятикратную разницу колонии; около 17 % на всём размахе от 10 до 10⁵.
- Почему 0.02:
  - это примерно две трети эффекта на кутикуле, который мы получили на тех же видах: −0.030 на единицу log10;
  - это втрое больше ожидаемого смещения от знаменателя «тело» (+0.005);
  - меньший эффект для обеих гипотез не важен.

**Исходы основного теста** — по дереву MCC.

| Исход | Условие | Чтение |
|---|---|---|
| **Поддержка H1** | 95 % ДИ β₂ целиком < 0 | у больших колоний мозг рабочих относительно меньше |
| **Поддержка H2** | 95 % ДИ β₂ целиком > 0 | у больших колоний мозг больше |
| **Эквивалентность (H0)** | 90 % ДИ β₂ внутри (−0.02; 0.02); это TOST, α = 0.05 | практически значимой связи нет; H1 и H2 опровергнуты в пределах ±0.02 |
| **Мал, но есть** | ДИ исключает 0 и лежит внутри ±0.02 | связь есть, но ниже SESOI; пишем «статистически видна, практически мала» |
| **Не решено** | остальное | данных мало для вывода; пишем ширину ДИ |

- **«Устойчиво»** добавляется к исходу, если:
  - объединённый интервал по 100 деревьям ведёт к тому же исходу;
  - 95 % интервал brms не противоречит ему.

  Иначе пишем, что именно расходится.
- **Проверки устойчивости** (раздел 8) исход не меняют. Если знак β₂ меняется в любой проверке с n ≥ 100, это выносится в аннотацию.

## 11. Deviations policy

1. **Журнал отклонений.** Каждое отклонение пишется в таблицу: дата; что изменено; почему; было ли оно до или после соединения с колониями. Таблица идёт в приложение препринта.
2. **До соединения** разрешено чинить измерение по воротам № 2–3: доразметка, флаги, пороги автофлагов. Каждое такое изменение пишется в журнал.
3. **После соединения** основная модель, правила отбора и SESOI не меняются. Любой иной анализ подписан как разведочный и идёт рядом с основным.
4. **Ошибка в коде,** найденная после соединения, исправляется. Публикуются обе версии чисел и разница.
5. **Если данных меньше ожидаемого** (например, не прошли неокрашенные) — запасной состав из `fast-path.md`, раздел 7. Модель и правила те же; n и мощность пересчитываются и пишутся.
