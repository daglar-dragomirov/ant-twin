## 2. Ворота перед основным тестом (раздел 5) — пройдены

- **Ворота № 3, правило Халлера.** PGLS-λ: log10 мозга ~ log10 тела + окраска + класс шага.
  - n = 270 видов, наклон 0.489 [0.447; 0.530], R² = 0.85, λ = 0.69. Статус **pass**.
  - Сверка с R (nlme corPagel, phylolm) — расхождение < 1e-6.
- **Синтетическая проверка конвейера** на реальном дереве, наборе видов и размерах колоний, β₂ = −0.03, 200 симуляций:
  - смещение +0.0008, RMSE 0.0037, покрытие 95 % ДИ 0.955;
  - средняя SE 0.0038 — мощность для SESOI 0.02 высокая.
- **Устойчивость R1–R14** на синтетике — все выполнены.

## 3. Отклонения от черновика v0.1 (раздел 11)

1. **Сегментация.** Вместо модели, обученной только на Toulkeridou 2023, используется ансамбль seg v3: nnU-Net 2d, 5 свёрток. Обучение — на Toulkeridou и 530 мозгах AntScan, одобренных визуальной проверкой.
   - Точность на отложенных видах по меткам Toulkeridou: Dice 0.962–0.973, |ошибка объёма| 1.0–2.6 %.
   - Повторяемость внутри вида (ICC(1) log10 мозга, 175 видов) — 0.90.
2. **Контроль качества масок.** Вместо ручной проверки — независимые визуальные агенты (Opus 5.5) по заданному протоколу. Вердикт «good» означает: бокс на голове и мозг целиком в боксе. Маски и вердикты хранятся в R2.
3. **Объём тела v8 вместо v6.** В v6 найдена ошибка: число срезов полного скана для сжатых TIFF оценивалось по размеру файла, ошибка 0.85–2.5×. В v8 точное число берётся из IFD0. Медиана отношения к S1 владельцев — 1.04 (было 1.15).
4. **Регистрация.** Вместо OSF — неизменяемый коммит и тег `ant-twin-prereg-v1.0` в репозитории на GitHub. Репозиторий пока приватный, время коммита и тега фиксирует сервер GitHub. Для OSF нужна учётная запись человека; её можно добавить позже как копию этого файла с датой коммита. При публикации препринта репозиторий или этот файл с историей открываются.
5. **Проверка с ошибкой измерения (brms)** выполняется после основного теста как заранее заданная проверка устойчивости. Если brms не установится, используется MCMCglmm. Это отклонение отражается в отчёте.
