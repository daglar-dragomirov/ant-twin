# ANT-TWIN — «Мозг роя»

Докторская 1.5.8: делает ли общество мозг особи меньше? Проверка на цифровых двойниках AntScan (2193 муравья, 792 вида, синхротронная микротомография, CC BY 4.0).

- Данные: полные стеки `biomedisa.info/media/antscan/processed/5x/<флакон>.tif` (BigTIFF, 8 бит, 2.44 мкм) читаются по частям через HTTP Range (`src/bigtiff_range.py`); уменьшенные стеки — `…/<флакон>_lowres/slice_NNNN.png`; таблицы владельцев — Zenodo 15546461.
- Эксперименты ведутся по пайплайну orx: один узел = одна git-ветка; команда запуска одна для всех узлов (`python -I run.py`), различается только код и `configs/experiment.json` в ветке.
- Все логи и результаты каждого запуска выгружаются в Cloudflare R2: бакет `dsc-biology`, префикс `ant-twin/` (см. `R2-LAYOUT.md`).
